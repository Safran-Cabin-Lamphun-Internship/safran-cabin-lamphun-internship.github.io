V22 EASY ADMIN

หน้านี้ออกแบบใหม่ให้แก้แบบ “เลือกหัวข้อแล้วแก้” ไม่ต้องค้นหา

1) เปิด /admin/ บน GitHub Pages
2) ข้อความหน้าเว็บ: เลือกหัวข้อ เช่น หน้าแรก / วิธีสมัคร / Contact แล้วแก้ EN/TH ได้เลย
3) ตำแหน่งฝึกงาน: แสดงแยกตามแผนก ไม่ต้องค้นหา กด แก้ไข ได้ทันที
4) กด ดูตัวอย่าง ก่อนดาวน์โหลด
5) กด ดาวน์โหลดไฟล์ แล้วนำ site-content.json ไปแทนไฟล์ data/site-content.json ใน GitHub

หมายเหตุ: ถ้าเปิด admin/index.html จากเครื่องโดยตรง Preview อาจทำงานไม่ครบ เพราะ browser จำกัดการโหลดไฟล์แบบ local; แนะนำเปิดผ่าน GitHub Pages
